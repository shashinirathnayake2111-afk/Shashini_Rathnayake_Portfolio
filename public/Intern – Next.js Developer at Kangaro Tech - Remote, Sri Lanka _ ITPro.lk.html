Intern – Next.js Developer

Kangaro Tech    Remote • Internship

Job Description

About the Role

KangaroTech is looking for a motivated and enthusiastic Next.js Developer Intern to join our Software Engineering team. This is an opportunity to gain hands-on experience working on real-world software projects, modern web applications, backend integrations, and cloud technologies.

We are looking for someone with a good foundation in web development, familiarity with Next.js, Java, and AWS, and a strong willingness to learn and grow as a software engineer.

Key Responsibilities

  • Develop and maintain responsive web applications using Next.js, React.js, and TypeScript.
  • Build reusable UI components and integrate RESTful APIs.
  • Work with backend services and databases.
  • Collaborate with the engineering team to implement new features and fix bugs.
  • Use Git and GitHub for version control and collaborative development.
  • Assist with application deployment and cloud-related tasks using AWS.
  • Work with Java and Spring Boot-based backend services where required.
  • Write clean, maintainable code and participate in code reviews, testing, and debugging.
  • Follow software engineering best practices and project documentation standards.

Requirements

  • Currently pursuing or recently completed a degree, diploma, or equivalent qualification in Software Engineering, Computer Science, or a related field.
  • Basic knowledge of JavaScript, HTML, and CSS.
  • Familiarity with React.js and Next.js.
  • Basic understanding of TypeScript.
  • Familiarity with Java and Spring Boot.
  • Basic understanding of REST APIs, databases, and backend development concepts.
  • Familiarity with AWS cloud services and application deployment concepts.
  • Basic knowledge of Git and GitHub.
  • Good problem-solving skills and attention to detail.
  • Willingness to learn new technologies and work collaboratively within a development team.

Good to Have

  • Personal or academic projects built with Next.js or React.js.
  • Exposure to AWS services such as EC2, S3, or RDS.
  • Familiarity with Docker and CI/CD pipelines.
  • Understanding of authentication, authorization, and database design.
  • A GitHub profile or portfolio showcasing previous projects.

What We Offer

  • A one-year paid internship with practical industry experience.
  • Opportunity to work on real-world software development projects.
  • Exposure to modern frontend, backend, and cloud technologies.
  • Technical guidance and opportunities to learn from experienced team members.
  • Experience with professional Git workflows, code reviews, and software delivery practices.
  • Opportunity to be considered for future full-time employment based on performance and business requirements.

Join KangaroTech and grow your software engineering career with us!
